Step 1: Install Dependencies (1 minute)
─────────────────────────────────────────────────────────────────────────────
pip install requests beautifulsoup4 --break-system-packages


Step 2: Run Scraper (2 minutes)
─────────────────────────────────────────────────────────────────────────────
python substack_archive_scraper.py "https://ruben.substack.com/archive?sort=new"

Result: Vault created in ./substack_vault/


Step 3: Open in Obsidian (30 seconds)
─────────────────────────────────────────────────────────────────────────────
1. Open Obsidian
2. File → Create new vault
3. Choose "Store in a folder on my computer"
4. Select the substack_vault folder
5. Open INDEX.md and start reading!

================================================================================
                         COMMAND REFERENCE
================================================================================

Basic:
  python substack_archive_scraper.py "https://ruben.substack.com/archive?sort=new"

Get 2024 articles instead:
  python substack_archive_scraper.py "https://ruben.substack.com/archive?sort=new" -y 2024

Custom output folder:
  python substack_archive_scraper.py "https://ruben.substack.com/archive?sort=new" -o ~/rubens_2025

Help:
  python substack_archive_scraper.py -h
